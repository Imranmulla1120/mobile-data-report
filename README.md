# Mobile Sales Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze mobile sales performance across different cities, payment methods, customer genders, and time periods.

The dashboard provides a comprehensive overview of revenue and unit sales using interactive visualizations and key performance indicators.

## Business Objective

The objective of this project is to analyze mobile sales data and understand:

- Overall revenue performance
- Total units sold
- Revenue contribution by payment method
- City-wise revenue performance
- Gender-wise unit sales
- Gender-wise revenue performance
- Monthly revenue trends

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Visualization
- Data Analysis

## Key Performance Indicators

- Total Revenue: 40.22M
- Total Units Sold: 50K

## Analysis Performed

- Analyzed revenue by payment method
- Compared revenue performance across cities
- Analyzed unit sales by customer gender
- Analyzed total revenue by customer gender
- Studied monthly revenue trends
- Created interactive filters for payment method and customer gender

## Dashboard Features

- Total Revenue KPI
- Total Units Sold KPI
- Payment Method filter
- Customer Gender filter
- Payment Method-wise Revenue Analysis
- City-wise Revenue Analysis
- Gender-wise Unit Sales Analysis
- Gender-wise Revenue Analysis
- Monthly Revenue Trend Analysis

## Key Insights

- The dashboard provides a high-level overview of mobile sales revenue and unit performance.
- Revenue is distributed across multiple payment methods, including credit card, online, debit card, and cash.
- Female customers contributed the highest unit sales and total revenue among the analyzed customer gender categories.
- The dashboard provides geographical insights into revenue performance across different cities.
- Monthly revenue analysis helps identify changes in sales performance over time.
